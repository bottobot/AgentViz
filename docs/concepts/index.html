AgentViz concepts

Eight separate ways to show what the stations map shows: a session moving data between processes, where it ends up, and in what condition. Each opens on its own and runs the same simulated live session (shared/sim.js). Click anything inside a concept to drill down.

    Reference: the current stations map runs inside VS Code (F5 → Run AgentViz → AgentViz: Open Activity → Show example). See README.md in this folder for the full note.
